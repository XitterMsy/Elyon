# Elyon

Ferramenta para organizar cálculos de recursos médicos, começando pela calculadora CBHPM.

## Rodar localmente

```bash
npm install
npm run dev
```

Para validar a produção:

```bash
npm run build
```

## Primeira versão

- Dashboard clean, responsivo e com modo claro/escuro.
- Cálculo manual de CBHPM para um ou vários procedimentos.
- Memória de cálculo detalhada, incluindo porte, UCO, filme e total.
- Regra de UCO de 100% para o principal e 70% para os demais.
- Histórico salvo automaticamente no navegador.
